# Retail Orders - Mini Data Analysis & Matplotlib Practice

A mini data analysis project focused on cleaning messy retail order data and creating visualizations using Python, Pandas, and Matplotlib.

## What's Inside
* **Data Exploration & Cleaning:** Identifying and fixing missing values, duplicate orders, inconsistent text formatting, and invalid date entries in `retail_orders_messy.csv`.
* **Data Visualization:** Analyzing product performance by plotting total quantity sold and top revenue-generating products using Matplotlib subplots.

## Tools Used
* **Python**
* **Pandas** (Data cleaning & aggregation)
* **Matplotlib** (Data visualization)
* **Jupyter Notebook**

## Files
* `matplotlib.ipynb` — Main notebook containing the data cleaning and plotting code.
* `retail_orders_messy.csv` — Raw dataset used for the analysis.
